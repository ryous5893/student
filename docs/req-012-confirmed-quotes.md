# REQ-012：確定済み見積と単価変更の仕様

- 対象Issue：[REQ-012](https://github.com/ryous5893/student/issues/12)
- 確認日：2026-11-18
- 確認対象：dev のコミット `6606d85`

## 利用者への回答

確定済み見積が単価変更後も前の金額で表示されるのは、現行の仕様です。確定時に保存した金額を保持するため、単価を変更しただけで既存の確定見積を計算し直す必要はありません。

未確定見積には変更後の単価が適用されます。確定済み見積は「見積」画面でそのまま参照できます。

## 再計算・再発行が必要な場合

現行版には、確定済み見積の再計算・確定取り消し・再発行を行う画面操作はありません。同じ注文の見積を新しい金額で再発行する操作手順は案内できません。

新しい金額での再発行が必要な場合は、対象の注文番号と希望する条件を運用担当へ連絡してください。元の確定見積の扱い、再発行の承認方法、見積番号・版の扱いは別途決定が必要です。本Issueでは再発行機能を追加していません。

## 確認した実装

- `app.js` の `confirmQuote`：確定時の計算結果を注文の `quoteSnapshot` に保存する。
- `app.js` の `renderQuotes`：`quoteSnapshot` がある場合は保存金額を表示し、ない場合だけ現在の単価で計算する。
- `app.js` の料金設定保存：`state.rates` を更新し、既存注文の `quoteSnapshot` は書き換えない。
- 通常の画面操作では、確定済み見積に「見積を確定」ボタンは表示されない。

金額保持の確認対象は、現行の確定操作で正常に `quoteSnapshot` が保存された見積です。保存金額が欠落したデータでは現在単価による計算にフォールバックするため、同じ保証の対象にはできません。そのようなデータが見つかった場合は、再発行と区別して別途調査が必要です。

## 動作確認

ブラウザの実データを変更しない、メモリ上の画面イベントテストで確認しました。

1. 初期データの104番（両面チラシ1,000部・標準紙）を20,000円で確定する。
2. チラシ単価を10円から12円、ポスター単価を120円から200円に変更する。
3. 104番の確定見積が20,000円のままであることを確認する。
4. 既存の102番の確定見積も3,660円のままであることを確認する。
5. 未確定の101番は新しい単価で4,200円になることを確認する。
6. 単価変更の前後で、注文データと保存済み見積が変わらないことを確認する。
7. 保存データを再読み込みしても、確定見積の金額が保持されることを確認する。

結果：すべて通過。確認した通常操作では仕様と異なる挙動は見つからず、業務ロジックの修正は不要でした。
